# お客様のために。 v0.9.8

崖っぷちの経営コンサルタントが再建困難なスーパーを救う、ブラックコメディの経営サバイバルゲーム。スマートフォン向けブラウザ／PWA。

## 今回の変更

- 6幕の導入ストーリー。最後に主人公が「炎上しない程度に消費者を騙そう」とつぶやき、悪魔の影が現れる。スキップ可能。
- **全6幕を専用の描き下ろしSVG一枚絵**に変更。事務所・養育費・依頼の電話・閑散とした店舗・契約書・夜の悪魔の影を、それぞれ異なる構図で描画。外部画像を使わず軽量。
- 経営ホームは事務所の絵、店舗資金、自分の財布、評判、今週の経営会議に集中。その他の詳細データは必要なときだけ開く。
- 提案・家計簿・経営詳細・決算・説明の各ポップアップに**閉じる**ボタン。表示中のダブルタップによる拡大を抑止し、通常のタップ・スクロール・ピンチは維持。
- 前回の決算は経営詳細から再確認できる。
- 経営エンジン、入出金計算、セーブキー `okyakusama.save.v1` に変更なし。
