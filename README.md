# お客様のために。 v0.9.7

- 事務所の店長・消費者の表情を固定座標のSVGへ置換し、小画面で崩れないようにした。
- 主人公の所持金・週差分を円単位で表示し、報酬・生活費・養育費の関係を明示。
- お金のポップアップは「開始残高 → 入金と支払い → 現在残高」を最優先し、1円単位の明細を折りたたむ。
- 導入を5場面に分割し、仕事が来る前の生活、養育費、電話、現地訪問、契約という時間経過を丁寧に描写。スキップ可能。
- 金額のゲームロジック、現行セーブ形式、3択・緊急再建の挙動は変更しない。
