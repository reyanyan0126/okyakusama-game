# 『お客様のために。』v0.7 — 経営に選択の重みを

架空のスーパー「モグモグマート」を12週間コンサルする、ブラウザ/PWA対応のブラックコメディ経営ゲームです。**既存のセーブは初期化しません**。既存版v0.1〜v0.6の保存データを引き継げるよう、同じ `okyakusama.save.v1` と互換性のある保存形式を使っています。

## v0.7で増えた実際のプレイ操作

- 「経営会議」→ 4つの経営施策から1つ選ぶ（これまでの操作を継続）
- **新たに「今週の投資」**を任意選択可能。「設備更新」「スタッフ育成」「常連づくり」の3系統、各2段階。投資なしも選択できます。
  - 投資資金はその週の現金から支出（資産投資のため損益と別会計）。翌週以降も投資効果が残ります。
  - 設備更新：冷凍庫・レジ故障リスクと事故コストを低減。
  - スタッフ育成：来客需要を増やし、接客に関する不満を抑制。
  - 常連づくり：客足と評判を継続的に改善。
- **新たに「事故の後始末」**。有料の事故が発生すると、決算後に「追加補償をして評判を守る」または「費用を抑えて不満を受ける」の判断が求められます。決定前に離脱してもセーブされ、再開できます。選択は1度限り。
- **ビジュアル決算**。1週間の売上、仕入れ、固定費、施策・事故費用を横棒で比較して最終利益を表示。現金残高、報酬、評判、満足、炎上度の増減をコンパクトに配置しました。
- 台詞・経営イベントはフィクション。現実の法令・企業を模した正確なシミュレーターではありません。

## 操作

タイトル → 「新しく始める」 → 依頼を受ける → 「提案を選ぶ」 → 施策を選び、投資をするなら追加で選ぶ → 「この案で営業する」 → 決算を見る → （事故が起きたら後始末を選ぶ） → 次の週。

## セーブと安全性

- localStorageに毎週自動セーブ。独自JSONを書き出し・読み込みできます。
- セーブ形式の `version=1` と既存の保存キーを維持。新しい投資状態 `upgrades` は既存のセーブがない場合のみ初期値が設定されます。
- 古い各週のリザルトはそのまま保持し、前の週へ遡って新しい事故後始末を強要することはありません。
- 本プロジェクトは `okyakusama-game` のみを変更。 `umalog` は変更しません。
