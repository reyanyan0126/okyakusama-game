# お客様のために。 v0.9.6

小さな経営コンサル事務所から、倒産寸前のモグモグマートを再建する12週間の風刺サバイバルゲーム。

## v0.9.6

- 事務所の壁に貼られた店舗の現場写真が、経営状態に応じて6種類（平常・客足低迷・危機・繁盛・炎上・閉店）に変化。売上や評判が好転すると来店客や商品が増える。
- 主人公の財布・店の資金・養育費未払いに応じて請求書が積み上がる。資金を取り戻すと観葉植物が増え、悪魔の契約が残っていると悪魔が出現。
- 状態判定は保存済みの経営数値から行う表示専用ロジック。セーブデータ構造やエンジンの経営数値には変更なし。
- 元の3択会議、詳細家計簿、経営危機・事故・根本原因対策、旧データ互換を維持。見た目に絵文字は追加せずSVGで統一。
- スマホの省スペースレイアウト、固定フッター、低モーション設定にも対応。
