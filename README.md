# お客様のために。 v0.9 — 経営会議のゲーム化（第1段階）

架空の貧乏コンサルタントが、倒産寸前の食品スーパーと自分の家計を守るブラックコメディ経営サバイバルゲーム。iPhoneなどのモバイルブラウザ向けPWA。

## v0.9の追加・変更

- 毎週の経営会議は **4択から3択** へ集約。社長の相談内容、以前の炎上、資金危機によって提示内容が変化する。
- **社長の推し案と臨時報酬**：特定の強引な施策で個人報酬5,000〜7,000円を獲得できる。ただし会社の資金から同額が出ていく。断ってもペナルティなし。損得を選ぶ余地を作った。
- **危機の予兆**：店舗資金、人員不足、設備未更新、炎上、養育費の期限などを経営会議で短く表示する。
- **画面整理**：詳細ステータスと設備投資を必要なときだけ開く折りたたみ式に変更。経営画面の固定フッターを維持。
- **絵文字廃止**：画面の絵文字を自作SVGアイコンへ置換。店舗イラスト、キャラクター表情、世論、営業アニメーション、事故速報、決算の統一を進めた。
- エンジンのセーブ形式 `VERSION=1`・キー `okyakusama.save.v1` を継続。旧バージョンのデータを消さない。

## 操作

タイトル → モグモグマートを受注 → 経営会議で予兆と社長の提案を見る → 3案から1つ選ぶ → 任意で投資や悪魔の契約 → 1週間営業 → 決算・事故対応 → 次週。
