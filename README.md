# 『お客様のために。』 v0.3

架空のスーパー「モグモグマート」を12週間コンサルする、無料のブラックコメディ経営ゲーム。

公開ページ: https://reyanyan0126.github.io/okyakusama-game/

## v0.3の変更

- 経営画面はスマホの画面高に収まるコンパクトレイアウト。ページ全体の縦スクロールを無効化
- 3つの切り替えメニューを画面下部に固定。iPhoneのセーフエリアに対応
- 世論・記録タブは中身だけ縦スクロール可能
- 毎週届く経営施策を4件に絞り、強引な策が多い週・堅実な策が多い週を用意
- 経営施策は8種から13種へ。従来の8種に加え、ポイント還元縮小・派手な宣伝・試食サービス・地元野菜フェア・レジ増員を追加
- 消費者の辛辣な口コミを多数追加。口コミ欄に毎回「架空」の注記を付けない（作品のフィクション表記は遊び方に残す）
- もともとの経営エンジン・ゲームの保存キー `okyakusama.save.v1`・保存形式バージョン1を保持
- Service Worker キャッシュを `okyakusama-v0.3-cache-1` へ更新

## 操作
1. 経営タブでその週の4提案から1つ選ぶ
2. 1週間営業して結果を見る
3. 世論タブで街の反応、記録タブで過去の決算を見る

## 保存に関する注意
ブラウザ内で自動保存。記録タブからJSONバックアップが可能。再インストール、Safariデータ削除の前にはバックアップ推奨。
