# お客様のために。v0.4

iPhone対応・架空企業の風刺コンサル経営ゲーム。

## 今回の更新
- タイトル画面 → 依頼一覧 → モグモグマート受注 → 経営 → 営業 → 決算のゲームフロー。
- 食品スーパーのみプレイ可能。飲食・アパレルは「準備中」と明示。
- 店長・消費者のオリジナルCSSキャラクターと表情アニメーション。
- 決算画面に評判・満足・炎上度の変化を表示。
- 経営施策の名前・一言説明をブラックコメディ風に変更。
- v0.3と同じセーブキー `okyakusama.save.v1` とゲームエンジンのデータ形式。
- iOS Safariホーム画面追加可能なPWA（manifest/アイコン/Service Worker）。

## 公開
- 静的ホスティング（GitHub Pagesなど）でルート配信。
- 将来のApp Store公開は、Apple Developerの登録、アプリとしてのラッピング、ネイティブ配布要件、ストア審査などが別途必要。現在のPWA公開はApp Store掲載とは異なる。
- 企業・人物・出来事はフィクション。実在企業の実名やロゴを使用しない。

## 遊び方
タイトルで「新しく始める」→依頼を選択。毎週4つの施策から1つ選び、12週間の経営を楽しむ。中断時は「つづきから」。記録画面でセーブを書き出せる。

## テスト
`node tests/engine.test.cjs`。ブラウザ表示とiPhoneでのセーブ・遷移は公開後も実機で確認。
