# 『お客様のために。』v0.6 — 経営にお金と事故を

**独立した架空スーパー経営ブラックコメディゲーム。** 現在プレイ可能な依頼先は「モグモグマート」1店舗です。現実の企業や人物とは無関係です。

## v0.6の追加

- スマホの経営画面は大きめの店舗・店長・消費者と、**残り資金／週利益／評判／炎上度**の4指標に集中。旧7指標の表示値・内部計算は削除しない。
- 4択を常時表示せず、**「提案を選ぶ」→施策カード→採用→営業演出→週次決算**に変更。
- **毎週の固定費（家賃・人件費・光熱費）と仕入原価**を支払い、売上から資金を回復する。利益と資金残高は混同しない。固定費は週155,000円を基準に人員で変動。
- **11種類のアクシデント・追い風**（冷凍庫故障、配送遅れ、大雨、欠勤、在庫廃棄、比較投稿の再燃、口コミ大当たりなど）。種別に応じて費用、客足、評判、炎上度に影響。
- 点検に投資すると設備事故が起きにくくなる。人員削減で欠勤時のダメージが増える。資金が厳しい時はつなぎ融資を選べることがあり、借金は毎週返済。
- 赤字が続いて資金ショートした場合、12週を待たずに契約終了。経営判断でリスクと結果が変わる。
- v0.6から新規契約した場合、12週で **累計利益100万円と評判50** を目指す。以前のv0.5までのセーブデータを読み込む場合、元の契約目標 **180万円** は維持する。
