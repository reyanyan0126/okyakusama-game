# お客様のために。 v0.8

架空の経営コンサルタントが、崖っぷちの食品スーパーと自分の生活を同時に守る、風刺サバイバル経営ゲーム。スマートフォン向けブラウザ/PWA版。1プレイ最大12週間。

## v0.8の変更

- 主人公の財布を店舗資金から分離。初期所持金28,000円、毎週の生活費7,000円、第4・8・12週に養育費36,000円。未払いが規定値を超えれば途中終了。
- 店舗資金がマイナスになると倒産・即終了。従来の経営選択、投資、事故対応も維持。
- 物価高・不況・行政の衛生監査・賃金改定・景気回復・補助金など6つの社会情勢。売上・原価・費用に反映。
- 悪魔の期限付き契約3種。初回契約後、期日到来時に返済や炎上の反動が発生する。契約には上限があり、最終週直前の踏み倒しは不可。
- 状況を絵で伝える自作SVGアイコンを増設。営業→事故速報→決算を段階表示。売上・費用・手元資金を視覚化。
- 既存キー `okyakusama.save.v1` を維持。旧v0.7のセーブ読み込み・継続をテスト済み。

## 操作方法

タイトル → 依頼を受ける → 社会情勢と資金を確認 → 「提案を選ぶ」で4択＋任意の投資・悪魔の契約 → 1週間の営業 → 結果確認。事故時のみ追加対応。
