# お客様のために。 v0.9.3

## 今回の更新
- **店舗資金と主人公の財布**：経営画面で残高と前週からの増減を並べる。営業利益と現金増減を明確に区別。
- **決算**：店舗・主人公それぞれの増減を優先表示。理由を短く表示し、内訳（売上・固定費・融資・投資・報酬・生活費など）は「資金の内訳を見る」で確認。
- **選択肢の整理**：経営会議の3案だけ先に表示。投資と悪魔の契約は「追加の行動（任意）」に収納。選択した追加行動は見出しに表示。
- **ブラックユーモア**：決算と世論に短い風刺コメントを追加。文章を増やすのではなく、見出しと一言に集約。
- 元の経営エンジン・セーブキー `okyakusama.save.v1`・資金と救済の計算式は変更しない。
- 既存セーブデータは継続利用できる。
