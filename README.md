# お客様のために。 v0.9.9

経営再建ブラックコメディ。新規契約は30週間・3章構成（累計利益255万円・評判50以上を目標）（第1章1～10週、第2章11～20週、第3章21～30週）。旧セーブは元の12週間を維持して継続。

- プロローグで電話が鳴る専用カット→受話する7幕の導入演出（省アニメーション設定に対応）
- 経営会議は原則3択。任意の投資と悪魔の契約は追加策に収納
- 利益/信用を見ながら最大30週間の再建。毎4週の養育費、契約終了前の悪魔返済。
- 朗報アクシデントの専用演出。朗報には事故補償選択を表示しない。
- 手元資金、報酬、生活費、養育費はこれまでどおり別会計。
- 保存：ブラウザ内 localStorage。旧12週間プレイと新30週間プレイを判別。

Game is fictional. Browser/PWA files are intended for future app packaging.
