# お客様のために。 v0.9.4

## 今回の更新
- 経営会議を「社長の相談→固定費と支払余力→リスク→作戦選択」に再設計。
- 店舗と主人公、それぞれのお金の流れをポップアップで確認可能。店舗資金・主人公の財布のカード、経営会議、3択、週次決算から開ける。
- 先週の残高→入金合計→支出合計→現在残高を1円単位で表示。
- 営業利益と実際の現金増減を分離して説明。旧記録で未取得の内訳は差額として明示し、勝手に経費を捏造しない。
- 画面の小型化、既存の保存形式・経営計算・ゲームバランスは維持。

テスト：`node tests/finance-v094.test.cjs` と `python tests/browser-v094.py` を実行。

現行はPWA（ブラウザ配信）。App Storeでの公開は別途審査が必要です。
