# お客様のために。v0.9.5

貧乏コンサルタントが、潰れかけのモグモグマートと自分の生活を救う12週間の風刺経営サバイバルゲーム。iPhone向けPWA。

## 今回の新要素：原因を見抜いて再建する

- 新しい契約では「冷蔵設備の老朽化」「人手不足」「常連客の流出」のいずれかが、店の赤字体質を生む。
- 経営会議で予兆を表示し、毎週の3択のうち1つに、問題に応じた「コンサルの根本対策」が登場。通常の営業施策と二者択一。
- 対策には2.4〜3万円の費用が必要だが、設備なら週1.2万円のロス解消と事故対策、人手不足なら客離れ解消と人材力改善、常連離れなら固定客の回復と評判改善。効果は残り期間中継続。
- 決算は修理費や廃棄ロスを明細に含め、全入出金と口座残高を照合。
- 旧セーブはそのまま継続。途中の契約に突然「構造問題」のペナルティを追加しない。
- 3択、固定フッター、コンパクトな事務所画面、イラスト中心の見た目を維持。
