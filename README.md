# 『お客様のために。』 v0.1

架空のスーパー「モグモグマート」を12週間コンサルする、無料の風刺経営シミュレーションです。

## 今できること
- 8種類の経営施策から毎週ひとつ選んで実行する
- 有能さ、悪名、報酬、店の世間評価、売上、炎上度、消費者満足度、不満を管理する（悪名は補助表示）
- 内部確率による炎上、不買運動、口コミイベント、後日発覚する「過去施策」イベント
- 売上・粗利益・成功報酬の自動計算
- 12週のエンディング／再挑戦
- ブラウザ内自動セーブ、セーブのJSON出力・読み込み
- オフライン表示用Service Worker（HTTPS公開時）

## 遊び方
1. `index.html`を開く（正式にはHTTPSのサイトにアップロードしてアクセス）。
2. 8つの施策から1つ選び、「この施策で1週間進める」を押す。
3. 結果を確認して12週間経営する。

端末のブラウザでセーブが保存されます。ブラウザを変更・履歴削除したときのために、JSONバックアップも使えます。ローカルの`file://`から開く場合、環境によって保存機能やPWAは制限されます。

## GitHub Pagesへの公開
1. **新規・独立した公開リポジトリ**をGitHubに作成する（既存の「うまログ」にはアップロードしない）。
2. このフォルダの `index.html`, `styles.css`, `app.js`, `engine.js`, `sw.js`, `manifest.webmanifest`, `icons/` を**リポジトリのルート**へアップロードする。
3. `Settings → Pages → Build and deployment`で`Deploy from a branch`を選び、`main` / `/(root)`を指定して保存。
4. GitHub Pagesの公開URLにHTTPSでアクセスし、各種操作とセーブを確認する。
5. iPhoneのSafariでページを開き、「共有」→「ホーム画面に追加」からショートカットを作る。

## 設計・権利
- 架空の企業・商品・イベントだけが登場します。現実の企業や消費者行動を示す正確な予測ではありません。
- 経営施策の計算結果および炎上確率はゲームバランス用のモデルです。
- 画像は自作SVGとCSSのみ、外部画像・音楽・API・解析SDKは使用しません。
- 公開タイトル・名称の商標検索などの最終確認は別途必要です。
- 未成年でも遊べるよう、実際の欺罔手順・違法表示の具体的実践指南ではなく、架空の結果とリスクを描いています。

## 技術
HTML/CSS/Vanilla JS。ユーザー登録不要。データはlocalStorage。乱数は状態に保存したシードベースの擬似乱数で、ゲーム保存後の続きも一貫して進みます。
