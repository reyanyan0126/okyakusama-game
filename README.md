# 『お客様のために。』 v0.5

独立したスマホ・PWA対応のブラックコメディ経営シミュレーション。

## v0.5 新要素
- 12週間の契約目標（利益180万円以上、評判50以上を同時に達成）と分岐エンディング。
- 毎週違う経営の悩み、社長からの無茶な相談、4つの具体的な対処方針。
- 炎上・過去施策の再燃から次週の「緊急会議」へ続く連鎖。
- 短期利益と信用のトレードオフを調整。謝罪・改善・責任転嫁などの対応を追加。
- プレイ中の画面には最小限の目標進捗、週次決算と最終決算には理由を表示。
- PWA、端末内自動セーブ、JSONバックアップを維持。

## 互換性
既存v0.1〜v0.4の `okyakusama.save.v1` と `version:1` を継続。既存データを初期化しません。旧セーブにない追加表示データは履歴から導出します。`main`を更新する前に元のコードをバックアップブランチへ保存すること。

## テスト
`node tests/engine.test.cjs` と `node tests/ui-smoke.test.cjs`。端末固有の画面やPWAキャッシュ更新は実機で再確認。

## 注意
登場する会社・人物・事件はフィクション。現実の経営助言ではありません。現在公開しているのはPWAであり、App Store掲載には別途審査・配布作業が必要です。
