# お客様のために。 v0.9.1 — 緊急再建会議

モグモグマートの経営危機を、プレイヤーの機転で切り抜ける経営サバイバル・ブラックコメディ。モバイル向けPWA。

## 更新内容

- 世論タブ「みんなのひとこと」の見出しと先頭カードの重なりを修正。
- 新規プレイ時の店舗を資金19.5万円・評判58・満足度61から開始し、経営不振を明確化。
- 店舗資金がマイナスになると本来は倒産。再建の可能性がある場合のみ「緊急再建会議」に移行。
- 再建策は支払延期交渉（負債増）、在庫処分（品質低下）、社長の私財拠出（関係悪化）の最大3案。現実に資金不足を埋められる選択だけ表示。
- 再建は1プレイにつき最大2回。社長の私財投入は1回限り、以降の社長臨時報酬が停止。諦めれば即ゲームオーバー。
- 旧セーブキーと基本データ形式を維持。緊急会議中の状態も保存し、再開できる。
- 下部タブ固定、3択の経営会議、オリジナルSVGなどv0.9の構成を維持。
