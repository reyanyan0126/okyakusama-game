# v3.2.1 PWA更新修正

v3.2.0の公開後、旧版を起動済みのブラウザで3.1.0表示が残る不具合を確認した。公開先184ファイルはコミットと一致していたが、Service Workerの事前取得が既存HTTPキャッシュを利用し、新しいCache Storageへ古いHTML/JavaScriptを複製していた。

修正: 事前取得を `new Request(url, {cache: 'reload'})` へ変更し、新しいキャッシュ名へ更新。ローカルストレージ・セーブ形式・会計・ゲームルールには触れない。

検証: 旧版の静的ファイルに1時間のHTTPキャッシュを付け、更新後の画面版番号を厳密に検証するよう強化。修正なしでは実表示3.1.0/期待3.2.1で失敗、修正ありでは新版へ切替、元セーブの完全一致と確定済み結果の再開に成功。`npm test` は20/20成功。

公開承認は受領済み。PRのCIと公開後の旧版タブ再開を確認してから、公開完了と報告する。
