# v2.2.0 ビジュアル完成度 — 開発・アート基準

## 現在の実装範囲（Milestone A）
v2.1.1（PR #25）を親とする開発ブランチ上で、五人の固定キャストID、五表情の参照先、セリフの感情判定を共通化した。世論画面には完成済みSVG肖像による人物紹介（必要時に展開）を追加。新しい高精細なアニメ塗り原画25点を制作したわけではない。

## 5人の人物設定（厳守）
- you: 独立した経営コンサルタント。濃紺のスーツとネクタイ。モグモグマートの店員ではない。
- boss: 利益と世間体を重視する社長。主人公や店長と別人物。
- manager: スーパーの現場責任者。エプロン・名札。柔らかな表情が基調。
- worker: 店長と区別できる顔立ち、髪型、服装の店舗従業員。
- customer: スーパーを日常的に利用する常連客。現在は森さんの既存SVGを参照。他の常連の差分は別途扱う。

## 表情
normal / happy / angry / sad / panic の五種類。CSSで髪や顔や腕を作成・変形しない。完成画像全体を切り替える。単なる感嘆符で怒りを表現しない。悲しみや失敗などの語を含む台詞は感嘆符より優先して解釈する。

## 今後のMilestone B（未完了）
5人×5表情＝25点の新規、高解像度の統一されたアニメ調イラストを制作・監修する。顔・髪・服のブレをなくし、iPhoneの高密度画面で実効解像度を確認する。スーパーの売り場、バックヤード、事務所、経営会議、ニュース、繁盛・閑散・炎上に対応する独立した背景を追加する。
