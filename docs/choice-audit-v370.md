# 4択の監査 · v3.7.0

GOOD は問題を直接改善する案、SAFE は効果と費用を限定する案、GREEDY は目先の収益を優先する案、RISKY は成果の振れ幅が大きい案、ABSURD は現場の常識を外れる奇策。分類は内部データで、プレイヤーへの正解表示には使わない。

## 通常課題と条件付き課題

左から第一候補。価格・容量・品質・人員が上限または下限に達した場合は、同じ行の補欠から繰り上げる。資金14.5万円未満で実行可能なら借入を確保する。第2〜24週の通常課題では未解決の根本原因に対する修理・採用・常連対策も優先する。4枠を守るため、可能な限り同分類が重なる枠を置き換える。
