# v3.4.0 人物整合性と仕事の見える画面

基準: main 5b80862d1bdd4e73dd0bbb9aa9d9e8271c1a2380 (v3.3.1)。公開先は https://reyanyan0126.github.io/okyakusama-game/ 。

## 人物設定と台詞監査

`character-canon.js` を設定の正本とした。名前・役職・性別の既存明記状況・年齢層・一人称・二人称・敬語・人格・平常/怒り/困惑/喜び・プレイヤー/他人物との関係・許容/禁止表現・出典を6人について記載。未設定の年齢・性別を断定しない。店長と従業員の元の丁寧な口調、社長の身勝手な命令口調、常連の辛口、悪魔の誘惑を維持。既存物語・報酬・シミュレーションは変更なし。

表示変換後の日本語2121文字列出現、発言999出現（重複を除く発言334種類）を抽出・監査。正確な範囲と全文・出典は `character-audit-v340.json`。コード上の出現数であり、全てが独立した台詞という意味ではない。動的な台詞生成、無記名の台詞、現在画面での画像はブラウザテストで補完する。

70種類の台詞を人物別に修正（店長23、従業員43、森さん4）。旧セーブ内の文章は書き換えず表示時に適用。数値、皮肉の対象、イベント結果を維持する。例: 「表にレジを打たせろよ」→「では、その表にレジをお願いできますか」。性別を理由に一律の女性語/男性語へ置換していない。

発言者と画像の誤対応は、匿名客等の7別名を森さんから分離、元従業員/元社員/残った社員の3ラベルを別の声として扱う、未知IDの主人公への代替を廃止。計11の対応規則を修正（発生回数ではない）。`社長の内緒話` を社長として明示。名前のない客・記者・経理等は画像なしで役職付きの発言にする。会話の入れ子引用を保持する。

別デザインの人物が焼き込まれた12場面イラストは本編の表示経路から撤去（資産ファイルは互換性のため残す）。人物を追加するための新規画像生成はなし。全身人物は仕事場、行動ラベル、道具アイコンと一緒に表示する。作画による新しい腕・脚の動きは追加せず、既存素材で表現する。

状態連動: staff不足→店長のレジ応援と2組の待ち客、fatigue高→疲れた従業員の交代休憩、sat高→レジ対応と笑顔の客、frust高→商品説明と不満表情、fire高→問い合わせ、cash低→支払確認。営業の段階でも行動が切り替わる。

一般客40枠は固定ID・素材の表情・行動・発言画像として自動割当しない方針を保持。現在の役割と表情に適合する素材だけ使う（全40人を無理に毎回表示しない）。同一画像に週ごとの架空アカウント/別人格を付与しない。特殊客は固定の買い物習慣に基づく短い問い合わせと従業員の応答を追加。外見・身体・年齢を迷惑行為の理由にしない。森さんと特殊客1の重複登場も避ける。
