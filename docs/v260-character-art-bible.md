# 『お客様のために。』v2.6 人物原画・場面アニメーション制作仕様

## 今回着手した実装（Milestone A）
- 世論画面の人物紹介で、主人公 / 社長 / 店長 / 従業員 / 常連客の5名それぞれに、通常・喜び・怒り・悲しみ・驚きの5表情を切り替えて確認できるUIを実装。
- 既存の完成済みSVGイラスト25種を利用。ベクター描画のためラスタ画像の不適切な拡大ではない。
- 経営の3コマ漫画に、登場人物・感情・場面のデータ属性を付け、人物画像全体の短い入場演出を追加。身体パーツ単位のCSS組み立てや髪・腕の個別アニメーションは禁止。
- 動きの軽減設定時は演出を完全に止める。会計・乱数・セーブ形式は一切変更しない。

## 本格原画の確定デザイン指示
### 描画仕様
- 25枚（5人物×5表情）を**人物別に同一の顔立ち・髪・体型・服装**で作る。統一した暖色系2Dアニメ塗り、落ち着いた線画、人物全体の胸上〜腰まで。モグモグマートを舞台とするためカフェや別業態には改変しない。
- 元絵の縦横比4:5。最終制作データの目標: 最低 **1024×1280px、透明背景PNG** で承認された人物全体の独立イラストを用意し、WebPへ圧縮後もiPhone Retinaで顔と目がつぶれないことを検証。オリジナル画像は公開用リポジトリへ個人情報や秘密を含まない状態で置く。
- 正面固定のコピーペースト25枚でなく、同じキャラに見える範囲で視線・肩・身振り・姿勢を変える。各表情は顔の違いで読めること。
- 文字・ロゴ・UI・背景は人物アセットへ焼き込まない。透過画像と別の舞台背景を重ねる。
- 主人公：濃紺スーツ、経営コンサルタント。社長とは顔を区別。
- 社長：経営者らしい服装と顔の特徴。主人公と年齢・髪型が同じに見えない。
- 店長：働く大人としての自然な表情、店舗エプロンと名札。全表情で同じ人物。
- 従業員：店長とは違う髪型・服装。従業員らしい身のこなし。
- 常連客：最初は森さんを固定し、後で斎藤さん・青木さん・田中さんの差分を追加検討。

### 品質確認の判定基準
1. 人物の顔、服、髪の形が25枚の間で一貫する。
2. 必要な表情を文字なしでも区別できる。
3. 手指・目・首・服の接続に破綻がない。
4. 画像の1枚当たりの表示密度と容量がiPhoneで適切。
5. 5人全員を同じ画面で並べても塗り・光・線の密度が揃う。
6. シーンの登場人物とセリフの話者が一致する。
7. 画面幅320〜430pxで潰れない。ボタンのタップ領域44px以上。
8. 怒り・喜び演出は強制ループさせず、モーション軽減を守る。
9. 既存の結果3コマ漫画・セーブ・30週間の計算に回帰なし。
